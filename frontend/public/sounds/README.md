# Thunder Sound Effects

Add your thunder sound files here for the lottery draw animation.

## Required Files

Place 1-3 MP3 files in this folder:
- `thunder1.mp3` (required)
- `thunder2.mp3` (optional - for variety)
- `thunder3.mp3` (optional - for variety)

## Where to Get Free Thunder Sounds

1. **Pixabay** (Recommended - No attribution required)
   - https://pixabay.com/sound-effects/search/thunder/
   - Look for short, punchy thunder claps (2-5 seconds)

2. **Freesound.org** (Free with attribution)
   - https://freesound.org/search/?q=thunder+clap
   - Filter by "Creative Commons 0" for no attribution

3. **Mixkit** (Free for commercial use)
   - https://mixkit.co/free-sound-effects/thunder/

4. **ZapSplat** (Free with attribution)
   - https://www.zapsplat.com/sound-effect-category/thunder/

## Tips for Choosing Good Thunder Sounds

- **Short duration**: 2-5 seconds works best
- **Sharp attack**: Look for sounds with a clear initial "CRACK"
- **Deep bass**: Good thunder has low-frequency rumble
- **Clean recording**: Avoid sounds with too much background noise

## Example Download (Windows PowerShell)

```powershell
# From Pixabay (you'll need to get the direct download link after logging in)
Invoke-WebRequest -Uri "YOUR_DOWNLOAD_URL" -OutFile "thunder1.mp3"
```

## File Format

- **Format**: MP3 (recommended) or WAV
- **Sample Rate**: 44.1kHz or 48kHz
- **Bit Rate**: 128kbps or higher for MP3
